# Draft: implementation case for agent identity and authorization

Status: unsent discussion draft for SHUKOU's review. Recipient/process eligibility, current submission channel and deadlines must be verified before sending. No affiliation, compliance or adoption is claimed.

MANOSUBE Agent Civilization OS is an Apache-2.0 public implementation that relates agent-produced software changes to project objectives, scoped authority decisions, subject/version-bound evidence and persistent state transitions. Its state and acceptance contracts are independent of a particular executor provider.

We offer the project as an inspectable implementation case for agent identity/authorization discussions. Relevant mechanisms include signature-verified grant declarations, explicit operation scope and version binding, separation of authority evaluation from execution, and retained lineage connecting a change with its completion grounds. The project does not define a universal agent identity standard or replace environment-level enforcement.

The distinction between capability, permission, execution receipt and sufficient completion evidence may help structure software-factory examples. We invite scrutiny of trust-anchor custody, delegated scope, stale evidence, actor replacement and non-mediated external actions. Existing public demonstrations are bounded; general effectiveness and independently operated adoption remain unestablished.
